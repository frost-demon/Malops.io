## 📖 About

This repository is my **living documentation** of the **Malops.io** reverse engineering challenges I've worked through. Each challenge ships with:

- 🗂️ The original **challenge files** (binaries, source, artifacts)
- 🔬 My **analysis** process (tooling, methodology, dead-ends)
- ✍️ A full **write-up** explaining the solve step-by-step

The goal is simple: document the journey, not just the flag.
